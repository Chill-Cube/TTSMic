# TTSMic
A program that allows you to run clean TTS through your microphone.
Written by Chill_Cube

## SETUP:
1) Download Python 3.10: https://www.python.org/downloads/release/python-3100/
2) Download VB Cable: https://vb-audio.com/Cable/
3) Run `pip install -r requirements.txt` to install all modules.
4) Enjoy!

## SETUP:
1) Run `main.py`
2) Set your microphone to CABLE Output (VB-Audio Virtual Cable) on your software of choice.
3) Type anything you want
4) Press Enter and it speaks!
